# Interstate '76 research references

The repository contains two related but distinct research tracks:

- **Original retail game `i76.exe`:** [mission execution and VM](mission_execution/README.md), [FSM runtime](fsm/i76_fsm_runtime_reference.md), [vehicle object runtime](vehicle_object_model/i76_vehicle_object_runtime_reference.md), and [level/resource formats](level_format/i76_runtime_level_and_terrain_format_notes.md).
- **Original public builder `I76EDIT.EXE`:** [editor research index](editor/README.md), [road and terrain serialization](editor/road_terrain_serialization.md), [intersection geometry and wheel-contact limitations](editor/intersection_geometry_and_driving_surface.md), and [object/FSM authoring contract](editor/object_fsm_serialization.md).

Treat original-binary instruction evidence, retail-corpus measurements, static deductions, and unverified hypotheses as distinct evidence tiers. Older GitHub reference notes may describe unresolved issues that later investigations have narrowed. Preserve those original documents as historical records while using the latest scoped reference for current conclusions.

This research does not authorize reconstruction or implementation of a replacement game or editor until explicitly requested.
