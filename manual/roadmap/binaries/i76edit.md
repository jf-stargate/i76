## 4. Topic-to-entrypoint navigation

### A. Editor startup, CRT allocator and editable-object lifetime

**Original-instruction, substituted Win32:** Follow [v35](../../../agent/runs/i76edit/i76edit-20261027T010513Z-3eb837e1/artifacts/V35_STARTUP_DECOMMIT.md) for `00424181 → 00424F00 → 00424FB0`, `004232E0/00423300/00423350 → 00425310/00425590`, free `00422FA0 → 00425260/004252C0`, page decommit `00425180` and heap termination `00424F40`. Native CRT code executes; Windows `HeapCreate/Destroy`, `VirtualAlloc/Free` responses are synthetic. [v34](../../../agent/runs/i76edit/i76edit-20261027T003326Z-25e3484f/artifacts/ORIGINAL_CRT_SBH_RESEARCH.md) checks block owner/free metadata and normal object roundtrip; [v33](../../../agent/runs/i76edit/i76edit-20261027T000144Z-3e91ae7d/artifacts/CRT_MALLOC_RESEARCH.md) isolates retry/new-handler failure branches. The executable-initialized small-block threshold is **480 bytes** in the recorded original PE; synthetic pointers are not original process addresses.

**Original-instruction/binary-static:** Editable object payload construction `00409840` (0x78-byte record), separate 12-byte list node `0041C430`, deletion `00409DC0 → 00409A60 → 0041C480/00422FA0`: [v31](../../../agent/runs/i76edit/i76edit-20261023T153200Z-64b4e9ad/artifacts/object_teardown_native_research.md), [v33](../../../agent/runs/i76edit/i76edit-20261027T000144Z-3e91ae7d/artifacts/CRT_MALLOC_RESEARCH.md). Distinguish CRT-managed payload from Windows-heap-managed list node, and distinguish editor workspace objects from game runtime vehicles/objects. **Unresolved:** genuine Windows heap faults, failed-node allocation cleanup in real process, malformed list metadata, SBH recommit/second-region lifetime, all startup/GUI paths.

**Runnable public checks:** [verify_sbh_shutdown.py](../../../agent/runs/i76edit/i76edit-20261027T010513Z-3eb837e1/scripts/verify_sbh_shutdown.py), [verify_original_sbh_anchors.py](../../../agent/runs/i76edit/i76edit-20261027T003326Z-25e3484f/scripts/verify_original_sbh_anchors.py), [verify_native_anchors.py](../../../agent/runs/i76edit/i76edit-20261027T000144Z-3e91ae7d/scripts/verify_native_anchors.py), [verify_public_anchors.py](../../../agent/runs/i76edit/i76edit-20261023T153200Z-64b4e9ad/scripts/verify_public_anchors.py); these are **PE byte/anchor validators**, not the missing private full Java execution scripts. [v35 validation](../../../agent/runs/i76edit/i76edit-20261027T010513Z-3eb837e1/validation.json) records 48/48 checks; it does not establish native Win32 execution.

### C. Terrain classifications, grids, materials and zone processing

**Historical + binary-static:** [editor reference](../../../ref/editor/road_terrain_serialization.md) describes 128x128 packed 16-bit exported `.TER` cells (material bits 15–13, unresolved bit 12, height low 12) and road kinds **0→surface 2**, **1→3**, **2→4**. These are *terrain classes*, **not** roadway render texture/UV assignments. Object stamping `0040A6E0` uses work-plane 1 and intersection classes `0x50/0x51→6`, `0x52/0x53→7` in surface plane 2: [v21](../../../agent/runs/i76edit/i76edit-20261023T013651Z-21de63e4/artifacts/editor_object_terrain_grading.md). [v22](../../../agent/runs/i76edit/i76edit-20261023T020247Z-70ae8183/artifacts/editor_smoothing_and_object_order.md) documents four material-2..4 smoothing passes; [v23](../../../agent/runs/i76edit/i76edit-20261023T023107Z-5ce8ac14/artifacts/original_editor_overlap_and_smoothing.md) derives inter-object height propagation and zone-sequential—not global simultaneous—smoothing from native branches plus synthetic models.

**Original-instruction with synthetic territory:** [v28](../../../agent/runs/i76edit/i76edit-20261023T062209Z-7504f18b/artifacts/original_terrain_service_zone_seam.md) executes `00412120/00412300` and native accessors `0041F150/0041F2B0/0041F3A0/0041F4A0` to establish editor work-plane stride **0x8004** per zone. Do not substitute an assumed 0x8000 or 0x10008 stride; a bad-stride negative control produced false attenuation. [v29](../../../agent/runs/i76edit/i76edit-20261023T065437Z-0e28a278/artifacts/V29_ZONE_FIRST_TOUCH.md) executes `00411BA0/00411B30/004125A0` with UI refresh substituted; automatic neighbor-zone assignment can happen with no newly painted valid height. [v30](../../../agent/runs/i76edit/i76edit-20261023T072227Z-ea5043d8/artifacts/zone_compaction_and_reuse.md) executes `00411BE0`, six 0x8004-byte plane moves, 200-byte zone records and slot reuse; deletion's destructor was still substituted in that run, independently followed by v31.

**Validation:** [verify_plane_stride.py](../../../agent/runs/i76edit/i76edit-20261023T062209Z-7504f18b/scripts/verify_plane_stride.py), [verify_v29_native.py](../../../agent/runs/i76edit/i76edit-20261023T065437Z-0e28a278/scripts/verify_v29_native.py), [verify_original_compaction.py](../../../agent/runs/i76edit/i76edit-20261023T072227Z-ea5043d8/scripts/verify_original_compaction.py), [v23_overlap_semantic_model.py](../../../agent/runs/i76edit/i76edit-20261023T023107Z-5ce8ac14/scripts/v23_overlap_semantic_model.py) (last is **analytical**, not original x86). **Unresolved:** exact authored-workspace intermediate planes, 80-slot exhausted/corrupt zone state, visual display refresh, hardware-exact smoothing arithmetic and causality for specific shipped terrain anomalies.

### D. Road and intersection geometry

**Historical retail corpus and binary-static geometry, not new accepted original-instruction editor runs:** [intersection face/socket analysis](../../../ref/editor/intersection_geometry_and_driving_surface.md) distinguishes road-ending signs from actual SDF/GEO intersection meshes; its static model maps **54 SDF definitions** (40 packaged geometry resources and 14 aliases). It reports **762 of 1,300** road endpoints matching actual transformed exterior polygon corners in X/Z within 0.05 units, alongside oblique-family offsets and official anomalies. A separate diagnostic samples **386 first-LOD placements / 13,661 footprint points** and compares height/material to polygon pavement. These are calculated geometric/packed-terrain observations, **not** original editor road-junction execution or measured physical collision.

**Historical input/audit paths:** [v17 road endpoint checkpoint](../../../scripts/ghidra_history/i76_editor_road_endpoint_intersection_edges_v17_research_checkpoint.zip), [v18 intersection mesh checkpoint](../../../scripts/ghidra_history/i76_editor_intersection_mesh_road_socket_v18_research_checkpoint.zip), [v19 GEO face checkpoint](../../../scripts/ghidra_history/i76_editor_full_geo_vertical_road_sockets_v19_research_checkpoint.zip), [v20 footprint checkpoint](../../../scripts/ghidra_history/i76_editor_intersection_ground_contact_and_grading_v20_research_checkpoint.zip). These binary archives are historical checkpoints, **not** renamed accepted run artifacts; an agent must inspect their provenance and contents before depending on an unlisted script/report. [v21–v23 object grading](../../../agent/runs/i76edit/i76edit-20261023T013651Z-21de63e4/artifacts/editor_object_terrain_grading.md) provides a possible authoring mechanism for surface 6/7 but **does not causally reproduce** specific retail footprints.

**Critical open separation:** visible `RSEG` pavement and intersection SDF/GEO polygons are distinct from the runtime terrain height/material and the collision consumer. Static seam fit is **not** measured wheel height or collision. Never repair historical shipped anomalies to force a fit without an explicit comparator.

### E. Editor object / FSM export and instance identity

**Historical binary-static:** [object/FSM reference](../../../ref/editor/object_fsm_serialization.md) maps editor export `0041B150` (normal 28-byte empty FSM payload), missing external `fsmcomp` compiler, generated eight-byte object instance keys, `.IXP` count plus `name[40],key[8]` pairs, and 108-byte top-level `OBJ` records. The editor exports instance identity, but cannot be assumed to compile all nonempty shipped FSMs. Workspace list insertion and reload order can change duplicate-resource ordinals (**code-derived hazard**, not reproduced session failure).

**Newer editor evidence:** constructor/list `00409840/0041C430`, property setters `00409CB0/0040F8C0`, loader `00409EB0`, move `00409A90`, zone metadata `00409E00`, destructor `00409A60`: [v22 ordering](../../../agent/runs/i76edit/i76edit-20261023T020247Z-70ae8183/artifacts/editor_smoothing_and_object_order.md), [v30 compaction](../../../agent/runs/i76edit/i76edit-20261023T072227Z-ea5043d8/artifacts/zone_compaction_and_reuse.md), [v31 original teardown](../../../agent/runs/i76edit/i76edit-20261023T153200Z-64b4e9ad/artifacts/object_teardown_native_research.md). These validate **editor** memory and zone transitions, not complete `.I76` export or retail FSM execution.

**Unresolved:** `fsmcomp` original binary/grammar, full editable workspace → exported FSM/OBJ identity parity, duplicate-key stability through genuine editor UI sessions, exporter uninitialized/reserved fields and compiled FSM sidecar compatibility.

### F. Editor-to-engine format and runtime boundary

**Historical formats, two independent executable interpretations:** editor `WREV 8` versus shipped `WREV 9` (13-byte longer `WRLD` prefix) and editable `ROAD` graph versus baked `RDEF/RSEG` strips: [road/terrain reference](../../../ref/editor/road_terrain_serialization.md), [retail level format](../../../ref/level_format/i76_runtime_level_and_terrain_format_notes.md). Engine road loader `0048E1A0` reconstructs RSEG edge Y from runtime terrain and renderer `0048E900` consumes strips; engine wheel terrain probe `00440740` and height/material readers are *engine* VAs. Editor program's `00421DF0` is a different executable VA. Compare **serialized bytes and documented consumer contracts**, not address equality.

**Engine cross-check with explicit limits:** engine [TER index](../../../manual/roadmap/subsystems/TER.md) and [accepted authentic M06 run](../../../agent/runs/i76exe/i76exe-20261028T174609Z-3f1f83f8/artifacts/AUTHENTIC_TERRAIN_PHYSICS.md) measure original runtime terrain sampling/contact on selected fixtures, not editor write equivalence. Retail scene list insert `004925F0` (head `00644200`) and potential physical surface candidate list are distinct; the scene-to-collision bridge remains unclosed in [cross-track review](../../../agent/runs/i76exe/i76exe-20261028T174609Z-3f1f83f8/artifacts/CROSS_TRACK_REVIEW.md). [Retail object lifetime history](../../../ref/editor/runtime_object_lifetime_notes.md) belongs to `i76exe`; do not import game CRT/vehicle ownership into editor object modeling.

**Unresolved:** independently demonstrate editable authoring `.I76` save→load→export byte correspondence, WREV adaptation and genuine runtime scene-contact use of intersection faces. Road-kind-to-TER class mapping **does not prove** rendered road texture/UV or wheel grip on intersection mesh.
