# VEH — vehicle construction and physical dynamics

**Primary binary:** `i76exe`. **Advisory scope:** original VCF/VDF/VTF/CDF vehicle assembly; class-1 runtime, controls/drivetrain, persistent root pose, wheel/tire state, suspension/contact and update callbacks. **Interfaces:** [ENG](ENG.md) supplies initialization/frame/dispatch and clocks; [TER](TER.md) supplies original ground heights/materials/normals; OBJ owns world-object identity/registration/refcounts; RES supplies retail assets; GEO/TMT own mesh and material caches; RND consumes transforms and cameras; AI/FSM supplies higher-level controls. VEH does **not** own WinMain ordering, terrain page loading, general world polygon collision, the renderer, or editor road-authoring code. Labels are functional, not recovered original modules.

## Evidence tiers and current gaps

**Binary-static:** class-1 descriptor callbacks, original direct integrator callsite, and general collision alternatives can be located. No claim that semantic class names equal original source names.

**Original-instruction with substituted services:** promoted two-stock-vehicle construction; controlled original transforms/camera; corrected math startup; original terrain-driven suspension/contact for 32 frames each with native original tire filter; real source bytes privately supplied. The old nonorthonormal result should be understood in its *missing-startup* context. The later near-unit result remains Ghidra/hardware-assisted, not a Windows parity oracle.

**Independent model:** comparison of VDF/WDF/GEO and terrain heights, Gram matrix / finite-state verifiers and selected x87 instruction checks. Not an independently implemented engine certified by pixel or collision tests.

**Inferred/unresolved:** untested runtime controller initialization and ordinary input delivery; complete `00463120` cockpit/weapon branch; vehicle/world collision, special four-point positive `00440740` return, persistent destruction/cache release, realistic controls/damage, hardware-wide x87 parity and native WinMain update schedule. The rendered road surface is not proven to equal its TER surface class.
