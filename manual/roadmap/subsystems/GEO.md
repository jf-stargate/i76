## 1. Identity and functional boundaries

GEO's research surface is **source mesh and part identity → original runtime geometry/section state → face/attribute preparation → RND polygon handoff**. Material *source* metadata belongs here; material/palette/texture acquisition and device output do not become GEO-owned merely because GEO refers to them.

| Boundary / owner | Distinction required for investigations |
| --- | --- |
| **VEH → GEO** | VEH's original `004AD6F0` VCF/VDF/VTF/WDF/CDF construction and `004B75A0` VGEO part instantiation choose parts and attach them to an OBJ graph. GEO parses/caches selected `.geo` bytes, prepares geometry variants and face/material data. VEH owns dynamics and selected body/weapon state, not pixel shading. |
| **MLD / OBJ → GEO** | MLD resolves mission ODEF/LDEF placement and class/resource requests; OBJ owns registered world roots, child identity and lifetime. A parented geometry instance is *not* a unique resource blob. Original `world_object+0x70` is class-1 runtime, `node+0x5C` the tested group-selected geometry pointer, and parser `context+4` is temporary. Do not conflate these layers. |
| **Static GEO vs vehicle GEO** | Historical extraction finds `ODEF/LDEF → SDF → SGEO/SOBJ → GEO` for static objects; some ODEF classes use VCF, not SDF. Accepted original-instruction stock-vehicle construction **does not** prove original SDF hierarchy parsing, static face material binding or original static draws. |
| **TER → GEO/RND** | M06 source `TER` tiles and adaptive leaves create transient terrain polygons; these are *not* stock `.geo` faces. TER owns sampled height/material classes and adaptive source selection. The shared polygon interface, clip and bin path crosses into RND; terrain class bits/`0xB4` header tokens are not authenticated texture names. |
| **RES → GEO** | Indexed resource lookup/open/size/release (`0046FFC0`/`0046FEE0`/`0046FD40` in accepted emulators), actual cache lifetime, ACT/LUM/MAP/VQM/M16/CBK/PAK/PIX/ZFS provision and failures are external services. GEO's `004469A0` cache-key/geometry-handle behavior is a tested local interface, not proof of the global RES implementation or cleanup. |
| **GEO → RND** | `0045CBE0` produces GEO-derived render records; `0045D100`/`0045D530` traverse primary/secondary trees; `00471FD0` submits source-backed polygons. `0047C8D0` projection, `0047BF00` clipping fallback, `0047CE40` command/edge/span building and `0047CB00` pixel callbacks are RND processing boundaries, not exclusively GEO-owned functions. |
| **Material identity vs appearance** | VTF logical `.MAP` slot, per-object TMT registration, cached TMT descriptor, descriptor frame basenames, GEO face `texture_name`, chosen MAP/VQM/M16 payload, source face RGB, palette index and final output bytes are **separate identities**. Filename and UV float presence alone never prove a runtime texture binding, interpolation rule, rendered color, alpha rule or palette association. |

**Source organization is unresolved.** Ghidra v97/v98 annotations, renamed functions, inferred `.c/.h` groupings and functional GEO/RES/RND ownership are research navigation only, **not recovered original source symbol names**. In particular, the recently accepted v98 symbol reconciliation tooling (merged [PR #91](https://github.com/jf-stargate/i76/pull/91)) is not new runtime proof. Consult original opcode/checksum evidence before assigning a function's role.

## 3. Evidence provenance ladder

1. **Reviewed technical contract / promotion:** the authoritative *accepted interpretation* is limited to [vehicle VCF/GEO/TMT promotion](../../../agent/promotions/vehicle_vcf_geo_tmt_20261023.md) and the separately accepted [renderer](../../../agent/promotions/rnd_software_renderer_20261031.md), [M06 terrain](../../../agent/promotions/m06_visual_terrain_20261031.md), [unified terrain/vehicle](../../../agent/promotions/m06_unified_terrain_vehicle_submission_20261031.md) and [shade-column](../../../agent/promotions/rnd_original_shade_column_20261031.md) decisions and associated living references. Original promotion records retain historical “candidate” language even after their containing PRs merged.
2. **O — accepted original-instruction-with-services:** a specific opcode was actually retired in a controlled Ghidra run, with original writer/consumer and exact limits, source identity and service ledger. A positive original return does not prove full retail Windows scheduling, hardware-x87 parity or service behavior.
3. **S — binary-static:** confirmed retail PE byte/call/xref/field argument trace, but no dynamic execution of that exact code under the asserted scene. For instance `00446F44 → 004796A0` is **S** for the GEO-time color conversion in #81, though `004796A0` itself executes **O** in the separate shade producer.
4. **D — independently derived/corpus extraction:** format decoders, hierarchy composition, source vertex transforms, UV/material export experiments and standalone verifiers. Useful for source identity and falsification but not automatically original runtime semantics. Legacy [model extraction](../../../ref/model_format/i76_vehicle_model_format_and_extraction_reference.md) and [material extraction](../../../ref/material_format/i76_material_extraction_reference.md) are historical checkpoints.
5. **X — externally supplied:** exact original resource bytes placed by a substitute provider, heap backing, scene poses/camera inputs, host CRT/trig/`_ftol` arithmetic, null texture returns, synthetic color table, context palette selection and intercepts. Record these at each boundary; do not “promote” their writes to O.
6. **U — unknown:** original ACT/LUM scene selection, executed `00446F44` with correctly installed scene palette, resolved TMT-to-face/texture frame, textured draw/UV and transparent-pixel rules, original static SDF geometry parity, original M06 draw/raster and complete original RGB output.

**Evidence is compositional only within one measured state.** #80's same-state terrain+vehicle submission cannot be concatenated with #75/#77/#81's separate stock-bus draw and raster histories to claim an original same-state rendered terrain frame. #81's `m02.act` byte provenance does not establish that M02 was selected for that bus scene. #77's 8,192-byte diagnostic table and #81's original 65,536-byte table ownership are different fixtures.
