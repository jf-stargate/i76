## 2. Authoring-to-runtime data pipeline

```text
i76edit (private original editor, separate address space)
  editable .I76 ROAD graph [0x50 disk/0x54 live; straight/cubic; link indices]
    ├─ 00402E70 curve coefficients / edge sampling / 004030C0 *5 horizontal export
    └─ 0040E3C0 generated-terrain scheduler
         object stamps -> road modes 0..5 -> object stamps -> 4 smoothing sweeps
         80x80 editable zone-ID map -> per-slot 0x8004-byte work planes
         plane-1 work heights + plane-2 surface assignments
         -> 004125F0 merge -> 0041AAA0 packed terrain zone writer
  output: BWD2 mission [WDEF/WRLD, TDEF/ZMAP/ZONE, RDEF/RSEG, ODEF/...]
          + .TER sidecar + referenced external SDF/GEO/material resources
                            |
                            |  file format / expected semantic interface ONLY
                            |  no demonstrated byte-identical editable roundtrip
                            v
i76exe (retail runtime, independently verified)
  004B3DB0 / 00493910 [TDEF] -> 00493960 ZMAP / 004939D0 ZONE
    -> 00471400 file mapping -> 00493080 runtime 128x128 PAGE POINTER GRID
    -> 00493550 height (4 cells + bilinear + 0.1)
       004927B0 material (coordinate rounding + top 3 bits)
       004931C0 normal -> 0046DC10 tire contact / 0043E530 surface fallback
    ├─ 00490A00 -> 004911E0 shared-edge adaptive leaves
    │   -> 004937C0 transform -> 00491A30/004922F0 polygon work
    │   -> 0047BF00/0047B8C0 clip -> 0048FE10 spatial bins
    │   -> 0048FAC0 original consumer [native raster still unproven]
    └─ 004B8780 RDEF/RSEG linked road strips -> separate visual/scene path
        [RSEG / intersection GEO scene registration != terrain samples
         != 0052B94C polygon collision candidate ownership]
```

**Version/serialization boundary (`E-static/C/G-static`):** The public editor writes WRLD **WREV 8**; shipped missions use **WREV 9** with a **13-byte longer WRLD prefix** before surface records. WRLD surface-property table has eight 20-byte entries. In the authenticated M06 WREV-9 reader, `004B8A10` copies records from WRLD chunk `+0x9F` into `00644220` (`G-exec`). Do not apply this WREV-9 byte offset to the editor's WREV-8 writer. An editable `.I76` `ROAD` descriptor is **not** an `RSEG` chunk. The editor's internal zone slots are **not** the runtime's `.TER` page pointers.

## 5. Road and terrain material distinctions

The editor grading controller stores selected material at `004379FC`; six passes are not six interchangeable geometric coats. Mode 0 counts sections. Mode 1 discovers the first valid section height. Mode 2 supplies missing heights and material 0 within a broader classifier region. Mode 3 repairs eight neighbors. Mode 4 paints material 2/3/4 **only on missing-height cells** of classifier class 2. Mode 5 uses neighbor repair/repaint restricted to class 2, where valid-height material **0..5** is writable but stamped **6/7** is protected. Modes 1–3 accept nonzero `00409210` classes (including before/after endpoints); modes 4–5 accept exactly return class 2. The classifier's ribbon tolerance uses signed int32 cross-products and strict `abs(cross) < max(abs(dx),abs(dy))`, not a Euclidean width test. Isolated 896-case original instruction validation applies to the integer classifier, **not** all x87 raster conversion. [Editor classifier](../../agent/runs/i76edit/i76edit-20261023T031245Z-fec7cae2/artifacts/CLASSIFIER_RESEARCH.md), [mode evidence](../../agent/runs/i76edit/i76edit-20261023T025734Z-5492075e/artifacts/editor_road_mode_precedence.md).

Objects stamp **rectangular cell bounds from editable ASCII dimensions**, not exact exterior SDF/GEO polygons. A first valid work-height can propagate through overlapping stamps, while later material writes may overwrite earlier class assignments; list order is zone-index traversal plus head-insert ordering, not global creation order. Smoothing center cells require valid height and class 2–4. Four complete sequential zone sweeps each use a local scratch plane, then copy back **before processing the next zone**. This can affect cross-zone samples in one nominal pass. No given shipped mission's anomalous cell has been causally assigned to this grading order. [Editor overlap](../../agent/runs/i76edit/i76edit-20261023T023107Z-5ce8ac14/artifacts/original_editor_overlap_and_smoothing.md).

**Material hypotheses versus measured counts (`C`):** 87,551/89,595 (`97.72%`) sampled `miss8` road centerline classes match road-kind 0→2, 1→3, 2→4; including equivalent physical-property records 2≈6 and 3≈7 yields 88,856/89,595 (`99.18%`). Repeated samples are not independent. The `miss8`/`miss16` 40-layout distinction matters. Original M06 WRLD properties and a kind-1 RSEG centerline at `(2480,48725)` returning class 3 were **separately** verified by game instructions; this one check does not execute the editor. A shared 20-byte physical-material parameter record does not make classes 2/6 or 3/7 byte-identical indices, geometric surfaces, or textures. [Historical editor survey](../../ref/editor/road_terrain_serialization.md), [M06 cross-track review](../../agent/runs/i76exe/i76exe-20261028T174609Z-3f1f83f8/artifacts/CROSS_TRACK_REVIEW.md).

**Visible materials are a separate unresolved interface.** WRLD points to ACT/LUM/TBL, terrain MAP candidates and resource-mode-dependent textures; `miss8` direct indexed `MAP` and `miss16` `MAP→M16/VQM/CBK` have different extraction paths. Independent exports use `I2D*` direct-MAP overrides for some static junction surfaces, diagnostic TER colors, world-repeat UVs and experimental RSEG overlays. Those are `D` decisions, **not** authenticated original renderer selection. The original ordinary `004922F0` work-header `+0x04` literal **`0xB4`** is not the `TER >> 13` class or a proven texture ID. Alternate terrain descriptors were not initialized to an authenticated visual result. Original adaptive subdivision's static source-material predicate `word >= 0x4000 && (word & 0xE000) != 0xA000` admits classes 2/3/4/6/7, but expresses a **topology/LOD decision**, not a final texture. [Material extraction](../../ref/material_format/i76_material_extraction_reference.md), [visual reference](../reference/engine/m06_visual_terrain.md).
