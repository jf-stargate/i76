## Scope and proposed decision

Promote the **bounded** source-to-table-to-raster contract established by merged [PR #81](https://github.com/jf-stargate/i76/pull/81): authenticated retail `m02.act` bytes, installed in an **externally constructed context**, were copied by original `004791E0` instructions; original palette calculations and `004796A0` nearest-color/cache logic produced 256 byte entries in **one** column of a 65,536-byte static table; original `0047CB00` consumed one resulting indexed entry and original `0047CC62` retired 210 byte stores. This **does not** establish original ACT/LUM selection, authentic vehicle material/color binding, complete table generation, a naturally returning producer, genuine RGB/textured scene rendering, full retail Windows operation, or RND-v1 completion.

This advances, but does not erase, merged [PR #77](https://github.com/jf-stargate/i76/pull/77): its 8,192-byte synthetic diagnostic table and corresponding 210 stores of byte `31` remain historically valid **only for #77**. #81 substitutes an original-produced column and stores byte `0` for the same controlled command color `0`, row `31`, index `7936`. The full producer owns 65,536 bytes, even though the tested callback's shade mask addresses only the first 8,192 bytes. The earlier [renderer promotion, PR #79](https://github.com/jf-stargate/i76/pull/79) was merged and is accepted history; its former candidate wording in the living reference is stale, but the original promotion record must remain unchanged.

## Selected source → table → callback contract

1. **Source and palette copy:** original `004791F7` computes context `+0xE8`, `00479202` copies **768 bytes** to `006432E0`. The experiment installed authenticated `m02.act` into a host-owned `0x500`-byte context at `3D000000`; original ACT/LUM selection was not executed. Entry 0 was `(1,1,1)` without retail normalization.
2. **Native storage and lookup:** original producer `004791E0` owns static `[0061B2A0,0062B2A0)` (65,536 bytes) indexed `shade*256 + color`. `00479220` initializes 512 DWORDs of signed squared differences `-256..255` at `0059B388..0059BB87` (pointer `0059BB88`) when absent; `0047923E` clears the 32,768-byte 5/5/5 cache at `0063B2E0..006432DF` to `FF`. Original `004796A0` searches palette candidates **0..254**, uses squared RGB distance, first-minimum tie and caches first result per quantized key at `00479733`. Independently searching every query without cache is **not** the original algorithm.
3. **One original-produced column:** null second argument selects computation; nonnull selects the 65,536-byte copy branch `0047924C` (LUM input identity is not established). For source color 0, `004793A4` writes 24 rows `31..8`; `004794AF` writes 8 rows `7..0`; `004794ED` repeats row 31 for 112 rows `32..143`; `0047950B` repeats row 0 for 112 rows `144..255`. Precisely **256 original stores**, with outcomes `0,43,59,249,250,251,252,254`. The harness deliberately stopped **before** `0047951E` increments to next column: no native `RET` or other original-generated columns.
4. **Numerical ownership:** the observed original calculation uses float32 storage/rounding; 96 conversions invoke `004BA090` / imported MSVCRT `_ftol` through IAT `004BC27C`, failing at unmapped `000C0BFC` without the service. The substituted service truncates measured finite ST0 toward zero, pops ST0, returns signed EDX:EAX and pops only the return address, preserving the x87 control word. Original native CRT instructions, exceptions, physical x87 tag/status, generalized numerical parity and nonfinite conversions were **not** observed.
5. **Indexed raster:** original `0047CC55` uses `(shade & 0x1F00) + command_color`, with a read window of 8,192 bytes (`32*256`) in this callback. For both accepted source-command callbacks, original byte writer `0047CC62` executed 210 stores at X 233..247, Y 313..326 on the **X-backed** 640×480 surface. All 210 reads used **index 7936** (shade row 31, color 0) and returned **byte 0** from the newly original-generated color-0 column. The 256-entry column's diverse values do **not** describe the 210 output pixels. Resulting sentinel-filled framebuffer SHA-256 `caf6c543352cfa5ebbaf808a36215a662389ff2f524a62e90ab73301960c6ff7`.
6. **Unresolved source binding:** static `004B8A10` reads ACT/LUM names at WRLD `+26/+33`, copies ACT to `004FA170`, and dispatches via `005DD2C4`; `0048DC60` updates palette context `+E8` and calls `004791E0`, but these selection/update sequences were **not** executed in the positive experiment. Their entry-zero normalization can differ. GEO constructor `00446C90` calls `004796A0` from `00446F44` on source section `+8/+9/+A`, storing the resulting index to runtime section `+8`; during **GEO construction**, #81 inherited a helper substitution returning `0`. The producer's own `004796A0` executed **original** code. Separate original `00478B80` may overwrite columns later, but was not executed. TMT names are not demonstrated RGB or texture semantics.

**Classification:** authentic bytes in a controlled context are **X-source selection + O-copy**; palette arithmetic, cache, 256 producer stores and 210 callback stores are **O** under service boundaries; independently reconstructed float32 recurrence/memory comparisons are **D**; callers/ACT-LUM/multiple paths are **S** where only opcode/xrefs were inspected; full scene-color ownership and selection are **U**.
