## Scope and precise decision requested

Propose promoting **only the bounded original-instruction-emulated** contract that joins: original registered-vehicle visibility production and same-record bucket consumption; original source GEO and real mode-dependent polygon projection/dispatch; original kind-6 96-byte draw commands, 32-byte fixed-point edges and deferred packed spans; original 13-DWORD framebuffer descriptor construction **under a supplied guarded allocator**; and 210 **original** `0047CC62` indexed byte stores from a **supplied diagnostic** 8192-byte shade table. A complete retail frame, original palette/color fidelity, source-backed image, M06 terrain surface or maintained engine are **not** candidate conclusions.

Method key: **O** = original retail x86 executed in Ghidra emulator with substitutions; **S** = independently checked retail static opcode/dispatch; **D** = derived numerical/verifier inference; **X** = external service/controlled input; **U** = unresolved. `proven` in a run's `findings.json` describes the run's bounded scientific judgment, not a preexisting canonical decision. The detailed technical wording, original PCs, byte offsets and field ownership are in the [proposed reference](../../manual/reference/engine/software_renderer.md).

## Original services versus supplied services (essential provenance distinction)

Original instructions execute through vehicle constructors/registration, selected camera callbacks, producer/queue/consumer/GEO, projected polygon fallback, CE40 command/edge, finalizer/spans, 74C60 descriptor copy and 7CB00/7CC62 byte output in a retained emulator. Source-backed GEO is authenticated; source resources pass through **supplied extraction and CRT/resource helpers**. Original selected input/physics/full render scheduling is not exercised.

Substitutes include controlled stock-root poses, selected active entry/time/camera parameters and depth range, OS/CRT heap and strings, Ghidra FS/SEH backing, math/trig/conversion and ancillary lighting/material services; null VQM/M16 texture acquisition; supplied initial draw buffers (91,148 bytes + 128 guards); supplied 307232-byte raster allocation at `3F000000`; and diagnostic table `0061B2A0` (8192 bytes) defined as `((i & 255) + (i >> 8)) & 255`, SHA-256 `9208ae951af7fe2624047061396611af79b718114d45bb918acf20ce1e0a6a7e`. Final raster bytes themselves are **original-written but test-colored**. Original palette `004791E0` stops at conversion import `000C0BFC`; raw heap initializer `00474C10` stops at `HeapCreate` `000C0FE2`; original release `00474D40` is static-only. A test table must **never** become a claimed retail palette reference.
