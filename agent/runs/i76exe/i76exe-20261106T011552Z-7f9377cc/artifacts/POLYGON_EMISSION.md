# Original polygon loops, reversal and fallback

## Leaf boundary versus emitter work order

Every linked leaf reaches original flatten completion 00491BE4. The observer captures the actual stack index sequence there, before facing/shading or emitter selection. Forward 00492270 recursively visits child A then B and emits terminal vertex_a. Reverse 004922B0 visits child B then A and emits terminal vertex_b. The walker includes inlined terminal cases and uses leaf +14 forward, +10 forward, +18 reverse, +0C reverse. A duplicated first index is appended temporarily for closing-edge processing; the captured boundary loop excludes that sentinel.

The model flattens the independently reconstructed graph and compares all indices of every leaf loop in every valid case. All source XZ shoelace areas are positive (counterclockwise when X is plotted right and Z up). For standard XYZ cross products this corresponds to a -Y normal. Crucially, both original emitters READ THEIR INDEX INPUT BACKWARDS while filling work vertices forwards. Thus the preclip work order is the REVERSE of the walker boundary or triangle input. For a renderer-neutral reconstruction, retain the distinction explicitly instead of assuming a graphics API's front-face convention.

Each polygons.jsonl row preserves the actual original emitter index order, the original full boundary loop, reversed work-source order, source/view float bits, packed sample and ordinary shade argument, and separate clip/bin status. The independent checker compares each original preclip work XYZ store to the exact reversed transformed source bits. This is stronger than matching an image's apparent orientation.

## Fan anchor and triangle fallback

After flattening, the walker searches edges in +0C,+10,+14,+18 order for a split whose two children are terminal. It uses that edge's midpoint as fan anchor. Otherwise unsplit adjacent edges select an existing corner through the original 00491C14..00491C74 branches. If no such corner is available, 00491C7D creates an additional A/O averaged vertex AFTER view transformation and averages the auxiliary coordinates. That vertex is not another original sampled terrain source vertex. No selected valid case executes this added-center branch; the independent verifier fails explicitly if it becomes necessary rather than silently treating it as sampled data.

The original projected-height scan uses transformed y/z (including the closing index) to compute an integer sign score. Only score==4-boundary_count reaches the two-plane whole-polygon eligibility test. Two original plane results must have their +0C terms <0. The whole polygon also needs matching quantized shade bands: the code tests ((shadeCode0 ^ shadeCode1)&0x1F00)==0. A failed eligibility test, differing shade bands, OR a whole-polygon emitter returning zero enters 0049209C triangle fallback. A polygon rejected by clipping can therefore be followed by successful triangle attempts from the same leaf.

The fan visits consecutive boundary pairs including the closing pair, skips a pair touching the anchor, and calls the selected emitter with [anchor,previous,next] only when the triangle plane +0C term is <0. Each original emitted triangle in the selected cases matches an independently reconstructed anchor and ordered adjacent boundary pair. We do not independently reproduce all float-sensitive plane/facing/shade decisions or guarantee the entire emitter-attempt sequence from camera inputs; actual attempts are retained as the oracle. Positive source loop winding alone does not imply every leaf emits a visible polygon.

## Clipping, insertion and attributes

004922F0 allocates work at the current arena cursor, writes type/descriptor token 0xB4 at +04 and record-type zero at +0C, copies reversed transformed XYZ and scalar shade (+14 of each 24-byte vertex), calculates maximum source-view depth and calls the original selected 0047BF00 preparation path. Ordinary +0C/+10 vertex words are not established source UV attributes. The class bits in TER are NOT copied into the header token. Original 0047BF00 near/far and 0047B8C0 screen clipping may create vertices with interpolated attributes; those projected/clipped vertices must not be identified with source terrain indices. Imported CRT memcpy copies only original-produced clip-stack bytes.

Zero clip count returns emitter failure without binning. A positive clip count reaches 0048FE10; insertion acceptance is checked separately by original arena cursor advance and final bucket membership.
