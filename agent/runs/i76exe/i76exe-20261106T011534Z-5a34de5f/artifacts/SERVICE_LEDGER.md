# Execution and service ledger

The owned `TerrainHarnessBase.java` derives from accepted #51's `I76_AuthenticTerrainPhysicsProbe.java`. Changes are mechanical: rename the class; add an overridable pre-instruction observation hook; remove the two read guards that rejected default-page addresses. No original bytes are patched and no height result is supplied. `evidence/provenance.json` records source hashes/blob IDs and a mechanical derivation check. The subclass omits vehicles, WRLD material loading, physics, camera and renderer execution entirely. Inactive inherited hooks are not evidence that those services ran.

Original E-tier instructions: TDEF parser/dispatch `00493910`, ZMAP/ZONE handlers, TER mapping wrapper `00471400`, setup caller `00493BD0`, grid initializer `00493080`, integer sample `00493160`, bilinear height `00493550`, class `004927B0`, query normal `004931C0`, inverse-square-root table initialization `00493C50` and original normal math helper. Authenticated mission/TER bytes are installed at private supplied memory; original parser derives page-pointer state. All 16,384 slots per configuration are independently checked. The Ghidra source image's zero-fill default is read without harness modification.

Active substituted services (counts and actual emulator PCs in `evidence/services.json`): CRT sprintf at IAT slot `004BC234`, formatting the single resource path; CRT stat at `004BC16C`, reporting a supplied available fixture; CreateFileA `004BC0D8`, CreateFileMappingA `004BC0BC` and MapViewOfFile `004BC0C0`, returning deterministic handles and mapped TER at `40000000`; host x87 FISTP at `004935EE`/`00493608`; CRT `_ftol` thunk `004BA090` for normal conversion, supplied truncation/pop. These external function PCs are Ghidra import placeholders; the IAT addresses are the retail anchors. No real Win32 file mapping, heap or resource cache is claimed. No active heap, resource-cache, audio, clock, palette, rendering, or trigonometric service is needed in this reduced experiment. The inherited reset supplies stack/scratch/global environment and CW 037F.

`alias` privately changes one ZMAP byte to repeat its left active neighbor; `bit12` XORs 0x1000 in every private TER word. Both transformations are explicit, reproducible and distinct from authentic mission observations. Other source bytes remain unchanged. The original parser and initializer execute after those modifications. `repeat` starts a fresh emulator and reproduces M06 trace/grid/default bytes exactly; it is not a fresh Ghidra database import repeat.

H-tier native shim: Python loads the authenticated PE sections into a private zero-padded virtual image, installs the **original-parser-produced** grid, observed default page, spacing and reciprocal, and supplies TER backing at the same address. Linux i386 `mmap2/read/write/exit` replace image loading and OS environment. Runtime grid contents are independently checked against the model before the native results are accepted. `native_sampler.S` calls unmodified original `00493160`, `00493550` and `004927B0` directly. Every x87 operation in these samplers executes on the CPU; FISTP is not intercepted. CW starts 037F. It does not call original normal code, external CRT/Win32, mission parser or gameplay in the native process. The mapped executable input and generated shim binaries remain private. There is no claim of retail Windows scheduling, page lifetime, native memory ownership or full-engine execution.

D-tier `coordinate_model.py`: independent checked source-byte resolver and rational arithmetic rounding to the specified 24/53/64-bit significands, including admission double rounding. It does not call a retail function, emulator or native runner. The verifier compares native ST0 as an exact fraction and Ghidra addressing as exact integers/words, recording emulator numerical disagreements separately. Normal outputs are emulated observations with finiteness/pointer and bit12-invariance checks, not independently certified vectors.
