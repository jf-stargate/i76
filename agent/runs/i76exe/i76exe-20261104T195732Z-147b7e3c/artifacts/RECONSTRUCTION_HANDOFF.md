# HZD handoff for independent reconstruction work

Safe interface now: `parse_hzd(bytes) -> owned Manifest {raw, ordered names[16], offsets[16]}` and a separate `report_dependencies(manifest, inventory, resource_mode)`. Parsing must not acquire resources, activate horizon state, build geometry, deduplicate slots or choose an active palette. Keep unknown/unsupported source opaque for inventory. This assignment changes no maintained C++ code.

Verified stock wire format: plain ASCII text, no header/version/count/signature, sixteen12-byte logical `.MAP` names, each followed by CRLF including the last, total224 bytes in all74 available specimens (33 distinct payload hashes). WRLD payload+0x086/13 is optional and may be empty. All ordered references are names; no numeric parameters, geometry, UV or palette fields were found. This is the observed stock profile, not historical universality.

The supplied independent Python reader deliberately accepts a conservative broader name width (1..15 ASCII bytes, letter first, then letters/digits/underscore/dot/hyphen) while requiring exactly16 CRLF records and no trailing bytes. It preserves the complete accepted source and duplicate/case/slot order. Unsupported delimiters, blank/empty records, paths, NUL, non-ASCII, oversize, truncation, missing or excess entries and trailing content reject before resource work. Fifteen is a safe16-byte runtime-name storage policy, not an original parser check; texture extension derivation needs its own capacity validation. A first implementation may choose exact twelve-byte stock names, but must label that as a narrower support policy.

Retail00401540 is not a safe parser template: it uses delimiters space/comma/tab/CR/LF, unbounded strpbrk and difference-length strncpy, clears255 bytes of an annotated256-byte stack array, and copies C strings to24-byte global rows with name/pair boundary at16. Later starts skip until CRT mask0x103 accepts a byte, not merely until non-whitespace. No source-size check or delimiter-null test. Sixteen is a destination loop bound. First token and later token starts differ. Missing entries or separators are unsafe; excess trailing content is ignored. Do not copy those behaviors into an independent parser.

Dependency interface: literal logical name per slot -> primary004474b0 result, optionally same-stem M16 from00471c10. Primary can use a literal MAP or decoded derived VQM (first-dot truncation) plus embedded CBK. Companion uses last-dot truncation and only attempts size/acquire in high-color mode005dd2a8==1. When the helper returns,0 is primary failure,1 primary-only success,2 primary+companion; HZD accepts1/2. The primary fallback high-color path can call00471840 with null and access primary+4 before an error return; FULLRES.LST also belongs to primary flagging, not just optional M16. All272 corpus logical names resolve through PIX/PAK:104 direct MAP,168 VQM+CBK with M16. Inventory availability and decode success must remain distinct statuses.

Suggested future loader result: sixteen owned slot leases `{name, primary, optional_m16}`, a graph of requested/resolved/unavailable candidates, and an explicit ready flag. Build into temporary owned state, release manifest after copying, and publish readiness only after every required primary succeeds. Missing optional companions can remain absent. Release all temporary leases on failure and atomically replace prior active state. This is recommended modern safety, **not original retail rollback**.

Retail runtime record `00504840+24*i` has16-byte name region and two32-bit pointer fields at+16/+20.00401510 releases each pair via00471e50, then disables. Original init overwrites without releasing and partial failure retains earlier pairs. Teardown skips optional when primary is null. Caller must not assume repeat initialization is safe. Repeated teardown on intact cleared pairs has a local no-op property only.

Rendering interface: ordered pair is selected at00504850+24*index;00471f00 chooses optional only if present and render context type==1, otherwise primary. Geometry, angular/compass meaning, index bounds across all states, UVs, blending and palette treatment remain deferred. Preserve slot order without assigning those meanings. Acquiring textures does not establish rendering correctness.
