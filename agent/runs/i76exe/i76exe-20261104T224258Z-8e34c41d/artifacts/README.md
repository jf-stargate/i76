# ZFSF archive and registered-resource contract

Independent original-binary research; base-game archive only. The supplied archive's 6,116 resources can all be safely enumerated, resolved by logical key and decoded with explicit LZO mode selection grounded in retail instructions. Every result matches the corresponding extracted resource. Registered multi-source selection is established statically and modeled synthetically; native acquisition/media/lifecycle compatibility remains unexecuted.
