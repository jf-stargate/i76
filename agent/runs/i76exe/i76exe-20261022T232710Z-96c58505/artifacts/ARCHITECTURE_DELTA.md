# Native vehicle resource integration — architecture delta

* The full original `004AD6F0` VCF sequence now directly reaches two real GEO constructor paths for each tested vehicle: `004469A0` (8-character geometry cache key and reference tracking) → registered-resource lookup → `00446C90` (parse `OEG.` geometry). Runtime geometry handle at `004469A0` return is non-null. Retail GEO bytes are supplied at the emulated file boundary, not reimplemented by the harness.
* `00449680` implements owner-specific texture-slot identity: hash of `(world_object_ptr, case-folded logical slot name)`. On miss it obtains a TMT resource through the resource service, invokes original TMT header decoder `0044AB90` to construct a frame-name table, then original `0044AC80` creates a per-world-object record pointing to the cached TMT descriptor. Verified for every registered VTFC record: GTSi 24 and bus 22. TMT cache and slot records are distinct owners; at least the initial TMT record carries a nonzero refcount. Reuse/release behavior under teardown remains open.
* The 46 TMT retail records reside in the `leprcn4t.pix`/`bus1t.pix` resource families; each supplies source names and concrete frames (`al11ftf4.map`, `xb11ftf1.map` for the first bindings). A VTF logical `.map` slot and its referenced `.TMT` container are different resource identities; the `.TMT` payload includes frame basenames decoded by `0044AB90`.
* The original variant resolver `004466C0` receives the existing GTSi or bus body node, loads a selected cache-backed mesh into node `+0x5C` for group 0, selects the cockpit mesh in group 4, then reacquires the initial group 0 mesh using its **identical cached pointer** without another GEO constructor. This is stronger than the earlier v2.2.0 synthetic mesh selection experiment. The node's structural class, parent, basis and position are stable across these actual loads.
* `004B75A0` remains the correct 100-byte VGEO-part instantiator, `004B7800` a different (120-byte) instantiation path; prior correction retained. `004AD6F0` constructs class-1 runtime in original VDF callback; `world_object+0x70` points to the final runtime. The outer parser context's `+4` is a temporary pointer, not the final owner.

**Evidence class:** original retail instructions in Ghidra emulator with exact stock resource bytes; some OS/graphics/CRT services substituted. No claim of full Windows retail process execution or complete visual rendering.
