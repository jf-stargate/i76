The coherent terrain, mission VM and resource-acquisition subsystems can plausibly span several original files. RES gives the best evidence for multiple structural subregions. FSM loading versus execution has different state and call patterns, but exact file seams remain ambiguous. TER has shared state crossing visibility and sampling; do not force a partition.
