## Original surface contract and initialization

Retail bytes and the read-only GZF audit agree for 459 instruction addresses. At `0047CB0C..0047CB21`, the callback reads pitch at descriptor +00, Y offset at +20, aligned base at +14 and X offset at +1C. At `0047CB6D/7C/8A`, a span computes `pitch * (y + Yoffset) + x + aligned_base + Xoffset`. These are byte-address contributions from DWORD fields, not dword-scaled framebuffer offsets. `0047CB2F` first copies command +28's pending packed span to the slot at command +30. This store executed twice here. The source span format remains `(x << 21) | (length << 10) | y`, X=233, length=15, Y=313..326.

The narrow original descriptor constructor is `00474C60(dst,width,height,external_base,mode)`. It builds 13 DWORDs locally, requests `width*height+32` bytes through imported `HeapAlloc` when `external_base=0`, aligns the returned allocation and copies all 13 DWORDs to the descriptor with original `REP MOVSD` at `00474D32`. For the controlled 640×480 call, the measured request was 307,232 bytes. Original instructions returned with: pitch +00=640; flags +04=`200001E0`; mode +08=0; capacity +0C=76,800 DWORDs; aligned base +14=`3F000000`; raw allocation +18=`3F000000`; X/Y offsets +1C/+20=0; inclusive maxima +24/+28=639/479; ownership state +2C=1. The backing was supplied by the test service at `000C0FFE`, with all 307,232 allocation bytes initially `A5` and 16-byte `CD` guards on each side. The resulting descriptor fields were original writes, but the heap handle was still zero and this was not the retail startup sequence.

The unserviced original heap initializer `00474C10` calls imported `HeapCreate` and stopped at `000C0FE2`. The original palette/shade-table producer `004791E0` was tested after original surface construction; it reached its first imported float-to-integer helper at `004BA090 → 000C0BFC` and stopped. ## Independent verification and controls

The standalone `verify_raster.py` neither invokes Ghidra nor imports the probe. It authenticates the EXE/GZF/ZFS, checks 459 GZF instruction byte sequences against retail PE, matches source GEO and upstream command/draw events with the unchanged accepted reproduction, decodes both commands' split spans, checks the original pending-slot stores, independently calculates every destination byte address, checks each measured table index/value and original writer PC/ordinal, compares the complete 307,200-byte framebuffer against an independently constructed sentinel-plus-pixels buffer, and checks the separately captured 32 guard bytes. It executed 3,601 positive assertions; 85 further assertions were executed during three deliberately rejected mutations (writer destination, framebuffer base and output byte). The private full positive trace, framebuffer and guards are byte-identical after a separately imported GZF. The verifier uses measured original shade-index registers; it does not independently rederive the full x87 interpolation trajectory from the command's float planes. That arithmetic remains unresolved beyond this measured index/value sequence.

The original behind-camera control at target Z=-50 produced no eligible draw/callback output and left all 307,200 bytes `A5`. The absent-surface case reached `0047CC25` and was guarded before its first unowned destination read at `000000E9`; it made zero pixel writes. The raw initializer and palette-producer failures are preserved in `evidence/controls.json`. Published `evidence/raster_results.json` contains all 210 changed byte stores and corresponding table-read registers, bounded source/command/span records, hashes and control summaries. Private full traces and framebuffer files are regenerated by `scripts/reproduce.py`, not committed.

The remaining essential prerequisite for **authentic color/material output** is original palette/resource initialization, including the float-to-integer service and authenticated palette source. For a **retail-owned framebuffer**, the OS heap/device/locking path through `00474C10` and callers must also be recovered. Neither prerequisite changes the verified bounded diagnostic pixel result.
